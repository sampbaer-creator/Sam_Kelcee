# Samuel & Kelcee Wedding Website

A live wedding website built for sharing event details, registry links, and collecting invitation requests.

The site is hosted on Microsoft Azure and includes a working PHP RSVP form connected to an Azure MySQL database. Guest submissions are saved securely in the cloud and can be viewed through an admin guest list page.

## Live Site

`https://samuelkelceewedding.info`

## Features

- Responsive wedding website
- Home, event details, registry, and RSVP pages
- PHP form validation
- Azure MySQL database for RSVP submissions
- Admin guest list page
- GitHub Actions deployment to Azure
- Secure database configuration with environment variables

## Tech Stack

- HTML, CSS, Tailwind CDN
- PHP
- Azure App Service
- Azure Database for MySQL
- GitHub Actions
